# Verse-numbering tables

`eng.vrs`, `rsc.vrs` and `org.vrs` say how verses are numbered in three traditions (English
Bibles, the Russian Synodal Bible's Protestant edition, and the original-language texts) and
how each maps to the original. They are copied unchanged from the SIL.Scripture resources of
[libpalaso](https://github.com/sillsdev/libpalaso) (`SIL.Scripture/Resources/*.vrs.txt`),
